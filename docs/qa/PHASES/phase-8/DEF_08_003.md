# DEF-08-003: `VibeEngine` uses simulation instead of `MiracleFork`

**Priority:** P0
**Status:** OPEN
**Reporter:** QA Agent

## Summary
`VibeEngine::miracle_fork` in `src/v_live/engine.rs` contains a TDD simulation that only broadcasts a JSON message instead of actually spawning a process via `MiracleFork`. This violates Pillar 5 (Orphan Purge) because there are no child processes to manage or reap.

## Reproduction
Run a test that checks for child processes of the `vibe` master (e.g., `test_SEC_202_orphan_protection`). The list of children is always empty.

## Expected Behavior
The engine should use `MiracleFork` to execute the Python logic.

## Actual Behavior
```rust
async fn miracle_fork(&self) -> Result<()> {
    // simulation for TDD
    let result = json!({ ... });
    VibeGateway::broadcast(result).await;
    Ok(())
}
```
No process is forked.
