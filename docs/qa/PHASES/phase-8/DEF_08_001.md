# DEF-08-001: `vibe --help` treated as target, hangs engine

**Priority:** P0
**Status:** OPEN
**Reporter:** QA Agent

## Summary
The `vibe` command handler does not intercept `--help` or `-h`. It treats the flag as a file target, which causes the `VibeEngine` to start and enter an infinite master loop, hanging the CLI.

## Reproduction
```bash
velo vibe --help
```

## Expected Behavior
The CLI should print the help menu for the `vibe` command and exit.

## Actual Behavior
```
🏛️  Vibe Engine Activated
Architecture Directive: Phase 8 (Vibe-Coding)
[Hangs]
```

## Suggested Fix
Update `src/cmd/vibe.rs` to handle `--help` before creating the engine.
