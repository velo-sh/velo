# DEF-08-002: Vibe port hardcoded to 8080

**Priority:** P0
**Status:** OPEN
**Reporter:** QA Agent

## Summary
The Vibe Gateway port is hardcoded to `127.0.0.1:8080` in `src/cmd/vibe.rs`. This prevents multiple vibe sessions from running on the same machine and breaks the ability to configure the port via environment variables or CLI flags, which is required for robust QA automation.

## Reproduction
1. Start `velo vibe app1.py`
2. In another terminal, start `velo vibe app2.py`
3. Second instance fails with `Address already in use`.

## Expected Behavior
System should honor `VELO_VIBE_PORT` or similar configuration.

## Actual Behavior
Hardcoded `8080` in `src/cmd/vibe.rs:21`.
