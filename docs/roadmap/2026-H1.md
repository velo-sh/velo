## Philosophy: The "Fan-Out" Strategy

Velo has moved from linear infrastructure building (v0.1-v0.6) to parallel domain execution.
**Phase Numbers** are Project IDs (Domain), not strictly chronological.
**This Document Order** represents the **Execution Priority**.
