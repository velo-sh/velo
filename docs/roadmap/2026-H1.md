## Upcoming Phases

### Phase 3.5: Ecosystem Integration (2-3 weeks)

**Goal**: Make Zygote seamless with popular frameworks

| Task | Description |
|------|-------------|
| uvicorn integration | `velo serve main:app` |
| gunicorn worker class | Custom Zygote-based worker |
| Docker image | Official `velo:python3.12` image |
| Cloud deployment guide | AWS Lambda, Cloud Run, Fly.io |

**Deliverables**:
- `velo serve` command
- Documentation for framework integration
- v0.3.5 release

---

### Phase 4: Static Analysis (4-6 weeks)

**Goal**: Analyze Python code to predict and optimize startup

| Task | Description |
|------|-------------|
| Import graph analysis | Build dependency tree at build time |
| Lazy import suggestions | Identify deferrable imports |
| Bytecode caching | Pre-compile .pyc files |
| Dead code detection | Warn about unused imports |

**Deliverables**:
- `velo analyze` command
- Import optimization report
- v0.4.0 release

---

### Phase 5: Velo Runtime (Long-term)

**Goal**: Full Python runtime with Rust optimizations

| Task | Description |
|------|-------------|
| ASGI server | Built-in HTTP server |
| Hot reload | Development mode with fast reload |
| Multi-process orchestration | Replace gunicorn entirely |
| Memory limits | Per-worker resource management |

**Deliverables**:
- `velo serve --workers 4`
- Production-ready for web apps
- v1.0.0 release
