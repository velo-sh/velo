## Crisis Management Checklist

### If Benchmarks Are Questioned
- [ ] Respond within 2 hours
- [ ] Acknowledge the concern publicly
- [ ] Publish full methodology immediately
- [ ] Provide reproducible test scripts
- [ ] Invite community verification
- [ ] Update claims if errors found (transparency > ego)
- [ ] Post-mortem blog post

### If Critical Bug Discovered
- [ ] Acknowledge within 1 hour
- [ ] Provide workaround if available
- [ ] Update GitHub README with known issue
- [ ] Fix in emergency release (<24 hours if critical)
- [ ] Communicate fix to all affected users
- [ ] Post-mortem analysis (what, why, how to prevent)

### If Negative Press/Commentary
- [ ] Don't respond immediately (wait 1-2 hours)
- [ ] Assess if criticism is valid
- [ ] If valid: Acknowledge, commit to improvement
- [ ] If invalid: Politely correct with facts
- [ ] Never engage in arguments
- [ ] Take conversations offline if heated
- [ ] Learn from feedback regardless
