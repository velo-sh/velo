## 🎨 Brand Guidelines

### Core Messaging

**Tagline**: "Python, Unchained"  
**Subtitle**: "The Instant Runtime that Python deserves"

**Elevator Pitch** (30 seconds):
> "Velo is a high-performance Python runtime built with Rust that makes your Python applications start 60 times faster. No code changes needed. Full compatibility with the entire Python ecosystem. Perfect for AI/ML inference, serverless functions, and development workflows where startup time matters."

### Voice & Tone

| Attribute | Description | Example |
|-----------|-------------|---------|
| **Technical but accessible** | Explain complex concepts simply | "Velo uses Zygote pre-warming - think of it like Android's instant app launching, but for Python" |
| **Confident but humble** | Back claims with data, acknowledge limitations | "60x faster startup in our benchmarks. Your mileage may vary - try it yourself!" |
| **Helpful, not salesy** | Focus on solving problems | "Struggling with Lambda cold starts? Here's how Velo can help..." |
| **Community-first** | Open source values shine through | "Built in the open with community feedback from RFC stage forward" |

### What We Are

✅ **Systems-level engineering** - Built with Rust, kernel-engineer mindset  
✅ **Performance-focused** - Benchmark-driven, data-backed claims  
✅ **Developer-friendly** - Zero code changes, intuitive CLI  
✅ **Community-driven** - Public RFCs, open governance  
✅ **Production-ready** - Comprehensive testing, security-first  

### What We're Not

❌ **A new Python implementation** - We wrap CPython, not replace it  
❌ **A magic bullet** - Startup optimization, not runtime speed  
❌ **Enterprise-only** - Open source, accessible to all  
❌ **Overpromising** - Honest about limitations and trade-offs

## 💡 Best Practices

### Content Creation
1. **Start with why**: Always lead with the problem we solve
2. **Show, don't just tell**: Benchmarks, demos, code examples
3. **Make it reproducible**: Link to scripts, share methodology
4. **Optimize for skimming**: Headers, bullets, tables, bold key points
5. **Include CTAs**: What should readers do next?

### Community Engagement
1. **Respond fast**: < 24 hours for all questions/issues
2. **Be helpful**: Even if it's "not our job" - point to resources
3. **Celebrate wins**: Highlight contributors, users, milestones
4. **Stay humble**: Thank people, admit mistakes, learn publicly
5. **Build relationships**: Remember names, follow up, stay connected

### Social Media
1. **Visual content wins**: Always include images/charts/code
2. **Thread for depth**: Use threads for educational content
3. **Engage, don't broadcast**: Reply, retweet, start conversations
4. **Timing matters**: Post when your audience is active
5. **Cross-pollinate**: Share across platforms with platform-specific formatting
