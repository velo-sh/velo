## 1. Executive Summary

This document serves as the implementation handover for Phase 6.1 stabilization efforts, specifically addressing **DEF-61-004: Protocol Version Socket Isolation**. The implementation resolves the critical 30-second timeout bug during binary upgrades by isolating Unix domain sockets by user and protocol version.

---

## 2. Technical Architecture

### 2.1 User-Isolated Socket Directory
Sockets are no longer stored in a shared `/tmp` directory. They are now isolated per user:
- **Priority 1**: `$XDG_RUNTIME_DIR/velo/` (Linux standard)
- **Priority 2**: `$TMPDIR/velo-{uid}/` (macOS/Generic)
- **Priority 3**: `/tmp/velo-{uid}/` (Fallback for long paths)

### 2.2 Version-Specific Naming
Sockets include the hexadecimal protocol version to prevent cross-version interference:
- Format: `velo-zygote-v{VERSION:02x}.sock` (e.g., `velo-zygote-v01.sock`)

## 3. Mandatory "Red Lines" (Architect Mandate)

All developers maintaining the Zygote IPC layer MUST adhere to these three security and stability invariants:

### 🔴 Red Line #1: Path Length Circuit Breaker (104 chars)
Unix domain sockets have a strict 108-character limit. To prevent `bind()` failures on macOS where `$TMPDIR` can be extremely deep:
- **Rule**: If the calculated path exceeds **104 characters**, the system MUST fall back to `/tmp/velo-{uid}/`.
- **Implementation**: Checked in `ipc.rs:get_socket_dir()` and `main.py:get_socket_dir()`.

### 🔴 Red Line #2: Double Permission Verification (0700)
To prevent security bypasses via `umask`:
- **Rule**: After `chmod 0700`, the directory mode MUST be re-read and verified.
- **Action**: Alert via `SECURITY` log if permissions are insecure (not exactly 0700).

### 🔴 Red Line #3: Atomic Cleanup Semantics
To prevent race conditions and detect misconfigurations during stale socket cleanup:
- **NotFound**: Ignore (socket was already removed by another process).
- **PermissionDenied**: **CRITICAL ALERT**. Indicates a major security or ownership mismatch.
