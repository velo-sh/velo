## 1. Summary

Phase 3.5 implements the `velo serve` command for zero-config ASGI/WSGI deployment with Zygote pre-warming.

```bash
velo serve main:app --workers 4 --reload
```

---

## 2. Motivation

Phase 3 established Zygote mode for fast Python startup. Phase 3.5 extends this to web applications by integrating with uvicorn as the underlying ASGI server.

### Goals

- **Zero-config deployment**: Single command replaces manual Zygote + uvicorn orchestration
- **Framework auto-detection**: Automatically preload FastAPI, Django, or Flask modules
- **Production-ready**: Worker pool management, health checks, graceful shutdown

---

## 3. Design

### 3.1 Architecture

```
┌──────────────────────────────────────────────────────────────┐
│                      velo serve                               │
├──────────────────────────────────────────────────────────────┤
│  ┌─────────────┐    ┌─────────────┐    ┌─────────────┐       │
│  │   CLI       │───▶│   Zygote    │───▶│  uvicorn    │       │
│  │  (Rust)     │    │ (preload)   │    │  workers    │       │
│  └─────────────┘    └─────────────┘    └─────────────┘       │
│        │                  │                  │                │
│        ▼                  ▼                  ▼                │
│  - Arg parsing      - Framework       - ASGI/WSGI           │
│  - Framework          detection        - HTTP handling       │
│    detection        - Module           - Hot reload          │
│                       preload                                 │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 Components

| File | Description |
|------|-------------|
| `src/serve/mod.rs` | Module entry point |
| `src/serve/runner.rs` | ServeArgs and uvicorn wrapper |
| `src/serve/framework.rs` | Framework auto-detection |
| `src/serve/worker.rs` | Worker pool management |

### 3.3 CLI Interface

```bash
# Basic usage
velo serve main:app

# All options
velo serve <app> [OPTIONS]

OPTIONS:
    --host <HOST>      Bind host (default: 127.0.0.1)
    --port <PORT>      Bind port (default: 8000)
    --workers <N>      Number of workers (default: 1)
    --reload           Enable hot reload
    --no-zygote        Disable Zygote integration
```

## 4. Framework Detection

Velo automatically detects frameworks from:

1. `pyproject.toml` dependencies
2. `requirements.txt`
3. `uv.lock`
4. Module name patterns (e.g., `django.core.wsgi:application`)

### Preload Modules

| Framework | Preloaded Modules |
|-----------|-------------------|
| FastAPI | `fastapi`, `pydantic`, `starlette` |
| Django | `django`, `django.core`, `django.conf` |
| Flask | `flask`, `werkzeug`, `jinja2` |
| Starlette | `starlette`, `starlette.routing` |
