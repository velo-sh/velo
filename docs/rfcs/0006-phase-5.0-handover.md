## 2. 🚨 安全红线 (SECURITY HARD RULES)

> [!CAUTION]
> 以下规则是 **强制性** 的，任何违反都可能导致 RCE 或 DoS。

### 2.1 Marshal 安全协议 (TOCTOU Prevention)

```rust
// ✅ 正确顺序 - 必须严格遵守
let data = fs::read(path)?;             // 1. 全量读入内存
let hash = sha256(&data[header_end..]); // 2. 内存中校验
if hash != header.content_hash {        // 3. 验证
    return Err(BundleCorrupted);
}
// 4. 只有验证通过后才能 marshal.loads()
```

```rust
// ❌ 错误 - 禁止流式读取+验证
// 这会导致 TOCTOU 攻击
```

### 2.2 内存限制 (DoS Prevention)

```rust
const MAX_BUNDLE_SIZE: u64 = 256 * 1024 * 1024; // 256MB 硬限制

fn load_bundle(path: &Path) -> Result<Vec<u8>> {
    let size = path.metadata()?.len();
    if size > MAX_BUNDLE_SIZE {
        return Err(BundleTooLarge);  // 必须拒绝
    }
    fs::read(path)
}
```

### 2.3 文件权限检查

```rust
fn validate_security(path: &Path) -> Result<()> {
    let mode = path.metadata()?.permissions().mode();
    
    // 拒绝 world-writable
    if mode & 0o002 != 0 {
        return Err(InsecurePermissions);
    }
    
    // 拒绝 /tmp 等共享目录
    if path.starts_with("/tmp") {
        return Err(InsecureLocation);
    }
    
    Ok(())
}
```

## 4. 📦 Bundle 格式规范 (Binary Format)

### Header 结构 (必须实现)

```rust
struct BundleHeader {
    magic: [u8; 4],             // "VELO"
    version: u32,               // 1
    content_hash: [u8; 32],     // SHA-256 of data section
    
    // Python 环境 - 必须精确匹配
    python_version: [u8; 16],   // "3.12.1"
    cache_tag: [u8; 16],        // "cpython-312"
    optimize_level: u8,         // 0, 1 (-O), or 2 (-OO)
    
    // 布局
    module_count: u32,
    index_offset: u64,
    page_size: u32,             // 4096
}
```

### ModuleEntry 结构

```rust
struct ModuleEntry {
    name: String,
    offset: u64,
    size: u64,
    crc32: u32,               // 快速校验 (~20 GB/s)
    source_hash: [u8; 32],    // 缓存失效用
}
```

### 对齐要求


## 5. 🐍 Python 端实现 (Import Hook)

### VeloFinder

```python
class VeloFinder(MetaPathFinder):
    def find_spec(self, name, path, target=None):
        if name in self.bundle.index:
            return ModuleSpec(name, VeloLoader(self.bundle))
        return None  # Fallback to standard import
```

### VeloLoader

```python
class VeloLoader:
    def exec_module(self, module):
        entry = self.bundle.index[module.__name__]
        
        # 1. CRC32 快速校验
        data = self.bundle.data[entry.offset:entry.offset + entry.size]
        if crc32(data) != entry.crc32:
            raise ImportError("Module corrupted")
        
        # 2. 加载代码
        code = marshal.loads(data)
        
        # 3. 设置 __file__ (指向原始路径)
        module.__file__ = get_original_path(module.__name__)
        
        # 4. 处理 __path__ (关键!)
        if hasattr(module, '__path__'):
            disk_path = find_disk_package_path(module.__name__)
            if disk_path:
                module.__path__.append(disk_path)
        
        # 5. 执行
        exec(code, module.__dict__)
```

## 8. ⚠️ 常见陷阱 (Pitfalls)

| 陷阱 | 后果 | 防范 |
|------|------|------|
| 流式读取+验证 | RCE (TOCTOU) | 全量读入后校验 |
| 无大小限制 | OOM DoS | 256MB 硬限制 |
| 忽略 `__path__` | 插件无法发现 | 追加磁盘路径 |
| 随机填充 | 压缩率下降 | 使用 0x00 |
| 无构建锁 | 文件损坏 | flock |
