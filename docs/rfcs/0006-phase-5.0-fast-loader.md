## 1. Executive Summary

### 1.1 Background

Phase 4.x delivered static analysis and security improvements. However, Python cold start is still bottlenecked by:

| Bottleneck | Current Cost |
|------------|--------------|
| sys.path search | ~10-50ms (N dirs × M modules) |
| File I/O (200 files) | ~4-10ms (cold start) |
| marshal parsing | ~1-2ms |

### 1.2 Goal

**5x faster cold start** through bundled bytecode loading:

```
Current:  Python → sys.path search → .pyc I/O → Parse → Execute
Fast:     Python → bundle.veloc → memoryview → marshal.loads → Execute
```

### 2.4 Bundle Format (.veloc)

Using **rkyv** for zero-copy index access and **BLAKE3** for integrity verification:

> [!TIP]
> **Why BLAKE3 over SHA-256?**
> - **10x faster**: ~3-6 GB/s vs ~0.5 GB/s (matches NVMe SSD speed)
> - **Equal security**: 256-bit output, 128-bit collision resistance
> - **Native Merkle Tree**: Built-in parallel hashing for Phase 5.3
> - **No length extension attack**: Modern architecture (based on ChaCha)
>
> **Why no CRC32?**
> - BLAKE3 is a **superset** of CRC32 functionality
> - CRC32 detects bit errors; BLAKE3 detects errors AND tampering
> - Maintaining both adds complexity with zero benefit
> - Removing CRC32 eliminates "false security" trap (devs might skip BLAKE3)

```rust
use rkyv::{Archive, Deserialize, Serialize};

/// Hash algorithm identifier (1 byte, forward compatible)
#[repr(u8)]
enum HashAlgorithm {
    Blake3 = 0,     // Default, recommended (3-6 GB/s)
    // Reserved for future:
    // Sha256 = 1,  // Legacy fallback (0.5 GB/s)
    // Sha3 = 2,    // Future standard
}

#[derive(Archive, Deserialize, Serialize)]
struct BundleHeader {
    magic: [u8; 4],           // "VELO"
    version: u32,             // Format version
    hash_algorithm: u8,       // HashAlgorithm enum (0 = BLAKE3)
    abi_tag: [u8; 32],        // "cp312-darwin-arm64"
    env_fingerprint: [u8; 32], // BLAKE3 from Phase 1.5
    module_count: u32,        // Number of modules
    index_offset: u64,        // Offset to module index
    content_hash: [u8; 32],   // Hash of entire bundle (algorithm per hash_algorithm)
    
    // Python Environment - Exact Match Required
    python_version: [u8; 16], // "3.12.1"
    cache_tag: [u8; 16],      // "cpython-312"
    optimize_level: u8,       // 0, 1 (-O), or 2 (-OO)
    page_size: u32,           // 4096 for alignment
}

#[derive(Archive, Deserialize, Serialize)]
struct ModuleEntry {
    name: String,             // "numpy.core"
    offset: u64,              // Data offset
    size: u64,                // Marshalled size
    hash: [u8; 32],           // Module hash (algorithm per header.hash_algorithm)
}
```

### 2.5 Import-Order Data Layout

Arrange module data by import dependency order for optimal cache hit:

```
Random order bundle:              Import-order bundle:
┌────────┬────────┬────────┐     ┌────────┬────────┬────────┐
│ torch  │ numpy  │ json   │     │ json   │ numpy  │ torch  │
└────────┴────────┴────────┘     └────────┴────────┴────────┘
     ↑        ↓        ↑           ────────────────────────▶
     └────────┴────────┘           Sequential read = prefetch
     Random access = cache miss    = cache hit
```

### 2.6 Key Optimization: No Search

```
Traditional Python import:
for path in sys.path:        # 5-10 directories
    for ext in ['.py', '.pyc', '.so']:
        if exists(f"{path}/{module}{ext}"):
            return load(...)
# = (5-10) × 3 × stat() calls per import

Velo Bundle:
modules = bundle.index.get(module_name)  # O(1) hash lookup
return bundle.data[offset:offset+size]   # Direct slice
# = 0 syscalls per import (bundle already in memory)
```

### 2.7 Zero-Copy Optimization

```python
class VeloLoader:
    def __init__(self, data: bytes):
        self.view = memoryview(data)  # No copy!
    
    def get_code(self, name):
        offset, size = self.index[name]
        # Only copy at final step (marshal requirement)
        return marshal.loads(bytes(self.view[offset:offset+size]))
```

### 2.8 Native Extension Handling

`.so`/`.pyd` files cannot be marshalled. Strategy:

```
Module types:
├── Pure Python (.pyc)  → Bundle (marshal)
├── Native (.so/.pyd)   → Filesystem (fallback)
└── Package (__init__)  → Bundle + path reference
```

### 2.9 Fallback Mechanism

```python
class VeloFinder(MetaPathFinder):
    def find_spec(self, name, path, target=None):
        if name in self.bundle.index:
            return bundle_loader_spec(name)
        return None  # Fallback to normal import chain
```

## 3. Security Protocol

> [!CAUTION]
> `marshal` is not designed for untrusted input. Strict protocol required.

### 3.1 Secure Loading Sequence (TOCTOU Prevention)

```rust
const HEADER_SIZE: usize = 128;  // Fixed header size
const MAX_BUNDLE_SIZE: u64 = 256 * 1024 * 1024;  // 256MB

fn load_bundle_secure(path: &Path) -> Result<Bundle> {
    // 0. Validate file size (DoS prevention)
    let file_size = path.metadata()?.len();
    if file_size > MAX_BUNDLE_SIZE {
        return Err(BundleTooLarge);
    }
    if file_size < HEADER_SIZE as u64 {
        return Err(BundleTooSmall);  // Can't even contain header
    }
    
    // 1. Read entire file to RAM (atomic)
    let data = fs::read(path)?;
    
    // 2. Parse header with boundary check
    let header = parse_header(&data[..HEADER_SIZE])?;
    
    // 3. Validate header_end doesn't exceed file size
    let header_end = HEADER_SIZE + header.index_size as usize;
    if header_end > data.len() {
        return Err(InvalidHeaderEnd);
    }
    
    // 4. Verify BLAKE3 content_hash
    let hash = blake3::hash(&data[header_end..]);
    if hash.as_bytes() != &header.content_hash {
        return Err(IntegrityFailed);
    }
    
    // 5. Validate all module offsets before any access
    let index = parse_index(&data[HEADER_SIZE..header_end])?;
    for entry in &index.modules {
        validate_module_entry(entry, data.len() as u64)?;
    }
    
    Ok(Bundle { header, index, data })
}
```

**Mandatory Sequence**:
1. Sanity Check: If file size > 256MB or < HEADER_SIZE, reject
2. Read entire bundle to RAM (no streaming)
3. Validate header_end boundary before access
4. Verify BLAKE3 content_hash
5. Validate all module offsets
6. ONLY THEN call marshal.loads()

### 3.2 Three-Tier Path Security

> [!WARNING]
> Path checks must validate Raw + Link + Canonical to prevent symlink bypasses.

```rust
fn validate_location(path: &Path) -> Result<()> {
    let blacklist = ["/tmp", "/var/tmp", "/dev/shm"];
    let check = |p: &Path| !blacklist.iter().any(|b| p.starts_with(b));
    
    // Three-tier check: Raw path + Read link + Canonicalize
    if !check(path) { return Err(InsecureLocation); }
    if let Ok(link) = fs::read_link(path) {
        if !check(&link) { return Err(InsecureLocation); }
    }
    if !check(&fs::canonicalize(path)?) { return Err(InsecureLocation); }
    
    Ok(())
}
```

### 3.3 File Permission Checks

```rust
fn validate_bundle_security(path: &Path) -> Result<()> {
    let metadata = path.metadata()?;
    let mode = metadata.permissions().mode();
    
    // Reject world-writable
    if mode & 0o002 != 0 {
        return Err(InsecurePermissions);
    }
    
    Ok(())
}
```

### 3.4 Unified BLAKE3 Verification

> [!NOTE]
> Single algorithm for all integrity checks. No CRC32 needed.

| Level | Algorithm | Purpose | Speed |
|-------|-----------|---------|-------|
| **Bundle** | BLAKE3 | Security + tampering + corruption | ~3-6 GB/s |
| **Module** | BLAKE3 | Per-module integrity (cache invalidation) | ~3-6 GB/s |

**Why unified?**
- BLAKE3 speed matches NVMe I/O — hash is no longer the bottleneck
- Single code path — simpler, fewer bugs
- Native Merkle Tree — ready for Phase 5.3 parallel verification

### 3.5 Marshal Recursion Limit (AUDIT-012)

> [!WARNING]
> Deeply nested bytecode can cause Stack Overflow via `marshal.loads()`.

**Mitigation**:
```python
import sys

# Set recursion limit before loading any module from bundle
MARSHAL_RECURSION_LIMIT = 1000  # Conservative limit

def safe_marshal_loads(data: bytes) -> object:
    old_limit = sys.getrecursionlimit()
    try:
        sys.setrecursionlimit(MARSHAL_RECURSION_LIMIT)
        return marshal.loads(data)
    finally:
        sys.setrecursionlimit(old_limit)
```

**Alternative (Rust-side validation)**:
```rust
const MAX_MARSHAL_DEPTH: usize = 100;  // Conservative limit

/// Rust-side marshal depth validation (BEFORE passing to Python)
fn validate_marshal_depth(data: &[u8]) -> Result<()> {
    let mut depth = 0usize;
    let mut max_depth = 0usize;
    
    for byte in data {
        match byte {
            // TYPE_CODE, TYPE_TUPLE, TYPE_LIST, etc. increase nesting
            b'c' | b'(' | b'[' | b'{' => {
                depth += 1;
                max_depth = max_depth.max(depth);
                if depth > MAX_MARSHAL_DEPTH {
                    return Err(MarshalDepthExceeded);
                }
            }
            // Closing markers decrease nesting
            b')' | b']' | b'}' => {
                depth = depth.saturating_sub(1);
            }
            _ => {}
        }
    }
    
    Ok(())
}
```

**Python-side fallback** (defense in depth):
```python
import sys
MARSHAL_RECURSION_LIMIT = 1000

def safe_marshal_loads(data: bytes) -> object:
    old_limit = sys.getrecursionlimit()
    try:
        sys.setrecursionlimit(MARSHAL_RECURSION_LIMIT)
        return marshal.loads(data)
    finally:
        sys.setrecursionlimit(old_limit)
```

### 3.6 Fingerprint Cryptographic Binding (AUDIT-001)

> [!CAUTION]
> Without cryptographic binding, attacker can forge bundle with valid hash but wrong fingerprint.

**Requirement**: `env_fingerprint` must be included in `content_hash` calculation.

```rust
fn compute_content_hash(header: &BundleHeader, data: &[u8]) -> [u8; 32] {
    let mut hasher = blake3::Hasher::new();
    
    // Include ALL header fields in hash (cryptographic binding)
    hasher.update(&header.magic);
    hasher.update(&header.version.to_le_bytes());
    hasher.update(&header.env_fingerprint);
    hasher.update(&header.python_version);
    hasher.update(&header.abi_tag);
    hasher.update(&header.cache_tag);
    hasher.update(&[header.optimize_level]);
    
    // Then hash the data
    hasher.update(data);
    
    *hasher.finalize().as_bytes()
}
```

> [!TIP]
> **Future (Phase 5.3): Ed25519 Signing**
> For supply chain security, bundles can be cryptographically signed:
> ```rust
> struct SignedBundle {
>     bundle: Vec<u8>,
>     signature: [u8; 64],    // Ed25519 signature
>     public_key: [u8; 32],   // Signer's public key
> }
> ```
> This ensures bundles come from trusted sources, not just that they're tamper-free.

### 3.7 Import Graph Integrity (AUDIT-005)

> [!WARNING]
> If import graph is tampered, module loading order can be manipulated.

**Requirement**: Import graph hash must be verified before use.

```rust
struct BundleHeader {
    // ...existing fields...
    import_graph_hash: [u8; 32],  // BLAKE3 of import_graph.json
}

fn verify_import_graph(bundle: &Bundle, graph_path: &Path) -> Result<()> {
    let graph_data = fs::read(graph_path)?;
    let computed = blake3::hash(&graph_data);
    if computed.as_bytes() != &bundle.header.import_graph_hash {
        return Err(ImportGraphTampered);
    }
    Ok(())
}
```

### 3.8 Offset Boundary Validation (AUDIT-007)

> [!WARNING]
> Malformed `offset`/`size` can cause out-of-bounds read (memory corruption).

**Requirement**: All offsets must be validated before access.

```rust
fn validate_module_entry(entry: &ModuleEntry, bundle_size: u64) -> Result<()> {
    // Check offset is within bundle
    if entry.offset >= bundle_size {
        return Err(InvalidOffset);
    }
    
    // Check offset + size doesn't overflow
    let end = entry.offset.checked_add(entry.size)
        .ok_or(OffsetOverflow)?;
    
    // Check end is within bundle
    if end > bundle_size {
        return Err(InvalidSize);
    }
    
    Ok(())
}
```

### 3.9 Read Atomicity with flock (AUDIT-015)

> [!WARNING]
> Without locking, concurrent build can corrupt bundle mid-read.

**Requirement**: Use `flock()` for read/write coordination.

```rust
use fs2::FileExt;

fn load_bundle_atomic(path: &Path) -> Result<Vec<u8>> {
    let file = File::open(path)?;
    
    // Shared lock for reading (blocks exclusive writers)
    file.lock_shared()?;
    
    let data = fs::read(path)?;
    
    // Lock released automatically on drop
    Ok(data)
}

fn build_bundle_atomic(path: &Path, data: &[u8]) -> Result<()> {
    let file = OpenOptions::new()
        .write(true).create(true).truncate(true)
        .open(path)?;
    
    // Exclusive lock for writing (blocks all readers/writers)
    file.lock_exclusive()?;
    
    file.write_all(data)?;
    file.sync_all()?;
    
    // Lock released automatically on drop
    Ok(())
}
```
