## 1. Executive Summary

### 1.1 Background

Phase 4.x delivered static analysis and security improvements. However, Python cold start is still bottlenecked by:

| Bottleneck | Current Cost |
|------------|--------------|
| sys.path search | ~10-50ms (N dirs × M modules) |
| File I/O (200 files) | ~4-10ms (cold start) |
| marshal parsing | ~1-2ms |

### 1.2 Goal

**5x faster cold start** through bundled bytecode loading:

```
Current:  Python → sys.path search → .pyc I/O → Parse → Execute
Fast:     Python → bundle.veloc → memoryview → marshal.loads → Execute
```

### 2.4 Bundle Format (.veloc)

Using **rkyv** for zero-copy index access:

```rust
use rkyv::{Archive, Deserialize, Serialize};

#[derive(Archive, Deserialize, Serialize)]
struct BundleHeader {
    magic: [u8; 4],           // "VELO"
    version: u32,             // Format version
    abi_tag: [u8; 32],        // "cp312-darwin-arm64"
    env_fingerprint: [u8; 32], // SHA-256 from Phase 1.5
    module_count: u32,        // Number of modules
    index_offset: u64,        // Offset to module index
    content_hash: [u8; 32],   // SHA-256 of entire bundle (security)
    
    // Python Environment - Exact Match Required
    python_version: [u8; 16], // "3.12.1"
    cache_tag: [u8; 16],      // "cpython-312"
    optimize_level: u8,       // 0, 1 (-O), or 2 (-OO)
    page_size: u32,           // 4096 for alignment
}

#[derive(Archive, Deserialize, Serialize)]
struct ModuleEntry {
    name: String,             // "numpy.core"
    offset: u64,              // Data offset
    size: u64,                // Marshalled size
    crc32: u32,               // Fast integrity check (~20 GB/s)
    source_hash: [u8; 32],    // Source file hash for cache invalidation
}
```

### 2.5 Import-Order Data Layout

Arrange module data by import dependency order for optimal cache hit:

```
Random order bundle:              Import-order bundle:
┌────────┬────────┬────────┐     ┌────────┬────────┬────────┐
│ torch  │ numpy  │ json   │     │ json   │ numpy  │ torch  │
└────────┴────────┴────────┘     └────────┴────────┴────────┘
     ↑        ↓        ↑           ────────────────────────▶
     └────────┴────────┘           Sequential read = prefetch
     Random access = cache miss    = cache hit
```

### 2.6 Key Optimization: No Search

```
Traditional Python import:
for path in sys.path:        # 5-10 directories
    for ext in ['.py', '.pyc', '.so']:
        if exists(f"{path}/{module}{ext}"):
            return load(...)
# = (5-10) × 3 × stat() calls per import

Velo Bundle:
modules = bundle.index.get(module_name)  # O(1) hash lookup
return bundle.data[offset:offset+size]   # Direct slice
# = 0 syscalls per import (bundle already in memory)
```

### 2.7 Zero-Copy Optimization

```python
class VeloLoader:
    def __init__(self, data: bytes):
        self.view = memoryview(data)  # No copy!
    
    def get_code(self, name):
        offset, size = self.index[name]
        # Only copy at final step (marshal requirement)
        return marshal.loads(bytes(self.view[offset:offset+size]))
```

### 2.8 Native Extension Handling

`.so`/`.pyd` files cannot be marshalled. Strategy:

```
Module types:
├── Pure Python (.pyc)  → Bundle (marshal)
├── Native (.so/.pyd)   → Filesystem (fallback)
└── Package (__init__)  → Bundle + path reference
```

### 2.9 Fallback Mechanism

```python
class VeloFinder(MetaPathFinder):
    def find_spec(self, name, path, target=None):
        if name in self.bundle.index:
            return bundle_loader_spec(name)
        return None  # Fallback to normal import chain
```

## 3. Security Protocol

> [!CAUTION]
> `marshal` is not designed for untrusted input. Strict protocol required.

### 3.1 Secure Loading Sequence (TOCTOU Prevention)

```rust
// CORRECT: Atomic verification
let data = fs::read(path)?;             // 1. Read entire file to RAM
let hash = sha256(&data[header_end..]); // 2. Verify in memory
if hash != header.content_hash { return Err(Corrupted); }
let modules = parse_bundle(&data)?;     // 3. Load from verified buffer
```

**Mandatory Sequence**:
1. Sanity Check: If file size > 256MB, reject (prevents OOM DoS)
2. Read entire bundle to RAM (no streaming)
3. Verify SHA-256 content_hash
4. ONLY THEN call marshal.loads()

### 3.2 Three-Tier Path Security

> [!WARNING]
> Path checks must validate Raw + Link + Canonical to prevent symlink bypasses.

```rust
fn validate_location(path: &Path) -> Result<()> {
    let blacklist = ["/tmp", "/var/tmp", "/dev/shm"];
    let check = |p: &Path| !blacklist.iter().any(|b| p.starts_with(b));
    
    // Three-tier check: Raw path + Read link + Canonicalize
    if !check(path) { return Err(InsecureLocation); }
    if let Ok(link) = fs::read_link(path) {
        if !check(&link) { return Err(InsecureLocation); }
    }
    if !check(&fs::canonicalize(path)?) { return Err(InsecureLocation); }
    
    Ok(())
}
```

### 3.3 File Permission Checks

```rust
fn validate_bundle_security(path: &Path) -> Result<()> {
    let metadata = path.metadata()?;
    let mode = metadata.permissions().mode();
    
    // Reject world-writable
    if mode & 0o002 != 0 {
        return Err(InsecurePermissions);
    }
    
    Ok(())
}
```

### 3.4 Hierarchical Verification

| Level | Algorithm | Purpose | Speed |
|-------|-----------|---------|-------|
| **Bundle** | SHA-256 | Security/tamper detection | ~500 MB/s |
| **Module** | CRC32 | Fast corruption detection | ~20 GB/s |
