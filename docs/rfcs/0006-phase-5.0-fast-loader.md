## 0. Research Findings (2026-01-02)

> [!IMPORTANT]
> Cold start benchmark shows **40% faster** with mmap bundle vs traditional I/O.

### Benchmark Results (200 modules × 20KB = 4MB)

| Scenario | Traditional | mmap Bundle | Single Read |
|----------|-------------|-------------|-------------|
| **Cold Start** | 4.21ms | 2.53ms | **0.85ms** |
| Speedup | 1.0x | **1.7x** | **4.9x** |

### Warm Cache (page cached)

| Scenario | Traditional | mmap Bundle |
|----------|-------------|-------------|
| Warm cache | 6.12ms | 5.50ms |
| Speedup | 1.0x | 1.1x |

### Key Insights

1. **Cold start**: Bundle is **40% faster** (key for serverless!)
2. **Warm cache**: Minimal difference (~10%)
3. **Single read + slice**: Fastest approach (**5x** in cold start)
4. **Serverless focus**: Cold start optimization is primary value

### Recommendation

- ✅ **Proceed** with bundle implementation for serverless
- 📦 Use **single read + slice** (not mmap) for simplicity
- 🎯 Target: Serverless cold start acceleration

## 1. Executive Summary

### 1.1 Background

Phase 4.x delivered static analysis and security improvements. However, Python cold start is still bottlenecked by:

| Bottleneck | Current Cost |
|------------|--------------|
| .pyc file I/O | ~100-200ms per large module |
| Bytecode parsing | ~50-100ms |
| Memory allocation | ~30-50ms |

### 1.2 Goal

**30% faster cold start** through mmap-based PyCode caching:

```
Current:  Python → .pyc I/O → Parse → Execute
Fast:     Python → mmap cache → Zero-copy load → Execute
```

## 2. Technical Design

### 2.1 Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                     Fast Loader Architecture                 │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│   ┌─────────────┐    ┌─────────────┐    ┌─────────────┐     │
│   │   velo run  │───▶│  Loader     │───▶│   Python    │     │
│   │   (Rust)    │    │  (mmap)     │    │  Interpreter│     │
│   └─────────────┘    └─────────────┘    └─────────────┘     │
│         │                  │                  │              │
│         ▼                  ▼                  ▼              │
│   - Fingerprint       - Cache lookup      - Execute         │
│   - Cache check       - Zero-copy load    - No re-parse     │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 Key Components

| Component | Description |
|-----------|-------------|
| `src/loader/mod.rs` | Loader entry point |
| `src/loader/cache.rs` | mmap cache management |
| `src/loader/pycode.rs` | PyCode serialization |
| `src/loader/fingerprint.rs` | Cache invalidation |

### 2.3 Cache Format

```rust
// Cache file structure
struct CacheHeader {
    magic: [u8; 4],        // "VELO"
    version: u32,          // Cache format version
    python_version: u32,   // 0x030C00 = 3.12.0
    abi_tag: [u8; 16],     // e.g., "cp312-cp312-darwin"
    fingerprint: [u8; 32], // SHA-256 of source
    code_offset: u64,      // Offset to PyCode data
    code_size: u64,        // Size of PyCode data
}
```
