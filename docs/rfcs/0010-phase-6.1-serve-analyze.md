# Part I: Background & Motivation

## 1. Summary

This RFC proposes enhancements to the Velo CLI, combining three complementary features:

1. **`velo serve`**: Zero-config ASGI/WSGI server wrapper (Uvicorn/Gunicorn "exoskeleton")
2. **`velo analyze --graph`**: Static import graph visualization and savings report
3. **CLI Polish**: Improved user experience, error messages, and timing display

These features work together to create "The Hook" - the entry point that makes users fall in love with Velo at first sight.

## 2. Motivation

### 2.1 The Problem

- Users currently need to type `uvicorn my_project.main:app --reload --host 0.0.0.0 --port 8000`
- The v0.6.0 Static Import Graph power is invisible to users
- Error messages are minimal and unhelpful
- Startup time improvements are not displayed

### 2.2 The Opportunity

- **`velo serve`**: One command to replace verbose uvicorn invocations
- **`velo analyze --graph`**: Show users exactly how much Velo optimizes their imports
- **Polish**: Make every interaction feel premium

## 3. CTO-Approved Technical Adjustments

> [!IMPORTANT]
> The following adjustments were mandated during CTO review to reduce risk and maximize delivery quality.

### 3.1 Instant Restart (Not Hot Module Replacement)

**Risk**: True Python HMR (in-memory hot module replacement) is extremely difficult and unstable (stale object references, state consistency issues).

**Velo's Advantage**: Ultra-fast startup (10ms).

**Decision**:
- ❌ DO NOT attempt complex in-memory hot replacement
- ✅ DO implement "Instant Restart" (kill process → restart in 20ms)
- **Rationale**: With 10ms startup, "kill + restart" is perceived as instant but is engineering-clean

### 3.2 Signal Handling for Uvicorn Proxy

**Risk**: When running server subprocess, Ctrl+C signal handling must be clean.

**Implementation Requirements**:
- Rust MUST own the Ctrl+C signal handler
- On exit signal, Rust kills child subprocess gracefully
- In dev mode, direct exit is acceptable

### 3.3 Enhanced "Savings Report" Output

**Requirement**: The `velo analyze` output must be a "bill" format for maximum user impact:

```
Startup Savings Report
======================
Modules analyzed:     540
Traditional Python:   2,160 stat() syscalls
Velo optimized:       0 stat() syscalls
Estimated time saved: ~180ms
```

### 4.1 Architecture Decision: Subprocess Model (ENG-P0-001)

**Mandated Architecture**:
```
┌──────────────────────────────────────┐
│ Rust (velo)                          │
│  - Owns signal handlers              │
│  - Spawns uvicorn/gunicorn as child  │
│  - Monitors stdout/stderr            │
│  - Kills subprocess on Ctrl+C        │
└──────────────────────────────────────┘
         │
         │ subprocess.spawn()
         ▼
┌──────────────────────────────────────┐
│ Python (uvicorn/gunicorn subprocess) │
│  - Normal server behavior            │
│  - Exits when killed                 │
└──────────────────────────────────────┘
```

**Rationale**: This is already the existing architecture in `src/serve/runner.rs`. Do NOT change to pyo3 direct call - it causes GIL/signal handling nightmares.

### 4.6 Platform-Specific Requirements (2026-01-04)

> [!IMPORTANT]
> The following platform-specific requirements were identified by macOS and Linux expert reviewers.

#### 4.6.1 macOS: FSEvents Latency (MAC-P0-001)

**Problem**: FSEvents on APFS can have 1-2 second latency by default due to kernel-level coalescing.

**Solution**: Configure low-latency mode:
```rust
#[cfg(target_os = "macos")]
fn configure_watcher(watcher: &mut RecommendedWatcher) -> Result<()> {
    use notify::Config;
    // Request 100ms latency instead of default 1s
    watcher.configure(Config::default()
        .with_poll_interval(Duration::from_millis(100)))?;
    Ok(())
}
```

#### 4.6.2 macOS: Signal Handler Reset in Fork (MAC-P0-002)

**Problem**: When uvicorn/gunicorn forks workers, signal handlers are inherited. This can cause zombie workers on Ctrl+C.

**Solution**: Reset signals in child processes:
```rust
#[cfg(target_os = "macos")]
fn spawn_server(cmd: &mut Command) {
    use std::os::unix::process::CommandExt;
    
    unsafe {
        cmd.pre_exec(|| {
            // Reset SIGINT/SIGTERM to default in child
            libc::signal(libc::SIGINT, libc::SIG_DFL);
            libc::signal(libc::SIGTERM, libc::SIG_DFL);
            Ok(())
        });
    }
}
```

#### 4.6.3 Linux: inotify Watch Limit (LNX-P0-001)

**Problem**: Linux default inotify limit is 8192 watches. Large projects may exhaust this.

**Solution**: Detect and warn user:
```rust
#[cfg(target_os = "linux")]
fn check_inotify_limit() -> Result<()> {
    let limit = std::fs::read_to_string("/proc/sys/fs/inotify/max_user_watches")?
        .trim()
        .parse::<usize>()?;
    
    if limit < 65536 {
        eprintln!("⚠️  Warning: Low inotify limit ({})", limit);
        eprintln!("   To fix: echo 65536 | sudo tee /proc/sys/fs/inotify/max_user_watches");
    }
    Ok(())
}
```

#### 4.6.4 Linux: Container Detection with Polling Fallback (LNX-P0-002)

**Problem**: inotify events may be delayed or missed in Docker/Kubernetes with bind-mounted volumes.

**Solution**: Detect container and use polling:
```rust
fn is_container() -> bool {
    Path::new("/.dockerenv").exists() 
        || std::fs::read_to_string("/proc/1/cgroup")
            .map(|s| s.contains("docker") || s.contains("kubepods"))
            .unwrap_or(false)
}

fn configure_watcher_for_environment(watcher: &mut RecommendedWatcher) {
    if is_container() {
        eprintln!("[Velo] Container detected, using poll mode for file watching");
        watcher.configure(Config::default()
            .with_poll_interval(Duration::from_millis(500)))?;
    }
}
```

#### 4.6.5 Linux: XDG_RUNTIME_DIR for Ephemeral Files (LNX-P1-003)

**Requirement**: Use `XDG_RUNTIME_DIR` instead of `/tmp` for IPC files:

#### 4.7.2 SIGTERM Handling for Kubernetes (CN-P0-002)

**Problem**: K8s sends SIGTERM before SIGKILL. Velo must forward this to uvicorn/gunicorn.

**Solution**: Handle both SIGTERM and SIGINT:
```rust
#[cfg(unix)]
fn setup_signal_handlers(shutdown_flag: Arc<AtomicBool>) -> Result<()> {
    use signal_hook::{consts::{SIGTERM, SIGINT}, flag};
    
    flag::register(SIGTERM, Arc::clone(&shutdown_flag))?;
    flag::register(SIGINT, Arc::clone(&shutdown_flag))?;
    Ok(())
}
```

**Signal Chain**:
```
K8s SIGTERM → Velo (Rust) → Forward to uvicorn/gunicorn → Wait for drain → Exit 0
```

#### 4.8.2 ASGI Lifespan Protocol (PY-P0-001)

**Problem**: ASGI apps use lifespan events for startup/shutdown:
```python
async def app(scope, receive, send):
    if scope["type"] == "lifespan":
        message = await receive()
        if message["type"] == "lifespan.shutdown":
            # Cleanup DB connections, flush writers
            await send({"type": "lifespan.shutdown.complete"})
```

**Solution**: Graceful shutdown must wait for lifespan completion:
```
1. SIGTERM/SIGINT received
2. Forward signal to uvicorn (triggers lifespan.shutdown)
3. Wait for uvicorn to complete lifespan (or timeout)
4. Exit cleanly
```

**Detection Hierarchy**:
```
1. VIRTUAL_ENV env var (activated venv)
2. .venv/ in project directory
3. venv/ in project directory  
4. uv-managed environment
5. System Python (with warning)
```

**Implementation**:
```rust
fn detect_venv(project_dir: &Path) -> Option<PathBuf> {
    // 1. Check VIRTUAL_ENV
    if let Ok(venv) = std::env::var("VIRTUAL_ENV") {
        return Some(PathBuf::from(venv));
    }
    // 2. Check .venv/
    let dot_venv = project_dir.join(".venv");
    if dot_venv.exists() { return Some(dot_venv); }
    // 3. Check venv/
    let venv = project_dir.join("venv");
    if venv.exists() { return Some(venv); }
    None
}
```

#### 4.9.2 Architecture Decision: Thread-Based (RS-P0-002)

**Decision**: Use thread-based concurrency for v0.6.1 (not tokio).

```rust
fn run_serve(config: ServeConfig) -> Result<(), ServeError> {
    // Main thread: subprocess management
    // Thread 1: file watcher (notify)
    // Thread 2: health server (tiny_http, optional)
    
    let shutdown = ShutdownCoordinator::new();
    shutdown.register_signals()?;
    
    let watcher_handle = if config.reload.enabled {
        Some(std::thread::spawn({
            let flag = shutdown.clone_flag();
            move || watch_loop(flag)
        }))
    } else {
        None
    };
    
    let health_handle = config.health.map(|h| {
        std::thread::spawn(move || health_server(h.bind))
    });
    
    // Run subprocess, wait for exit or shutdown signal
    let mut child = ManagedChild::new(cmd, config.pid_file)?;
    let status = child.wait()?;
    
    Ok(())
}
```

**Future**: Migrate to tokio in v0.7.0 if needed for HTTP/2 or more complex async.

#### 4.9.3 Child Process RAII (RS-P0-003)

**Requirement**: Use RAII for child process cleanup:

```rust
struct ManagedChild {
    child: std::process::Child,
    pid_file: Option<PathBuf>,
}

impl ManagedChild {
    fn new(mut cmd: Command, pid_file: Option<PathBuf>) -> Result<Self, ServeError> {
        let child = cmd.spawn().map_err(|e| ServeError::ServerStartFailed {
            reason: e.to_string(),
            exit_code: 1,
        })?;
        
        if let Some(ref path) = pid_file {
            std::fs::write(path, child.id().to_string())?;
        }
        
        Ok(Self { child, pid_file })
    }
    
    fn wait(&mut self) -> Result<ExitStatus, ServeError> {
        self.child.wait().map_err(Into::into)
    }
    
    fn kill(&mut self) -> Result<(), ServeError> {
        self.child.kill()?;
        self.child.wait()?; // Reap zombie
        Ok(())
    }
}

impl Drop for ManagedChild {
    fn drop(&mut self) {
        // Ensure child is killed and reaped on panic
        let _ = self.child.kill();
        let _ = self.child.wait();
        
        // Cleanup PID file
        if let Some(ref path) = self.pid_file {
            let _ = std::fs::remove_file(path);
        }
    }
}
```

#### 4.9.4 Shutdown Coordination (RS-P0-004)

```rust
use std::sync::atomic::{AtomicBool, Ordering};
use std::sync::Arc;

struct ShutdownCoordinator {
    flag: Arc<AtomicBool>,
}

impl ShutdownCoordinator {
    fn new() -> Self {
        Self {
            flag: Arc::new(AtomicBool::new(false)),
        }
    }
    
    fn register_signals(&self) -> Result<(), ServeError> {
        #[cfg(unix)]
        {
            signal_hook::flag::register(
                signal_hook::consts::SIGTERM,
                Arc::clone(&self.flag),
            )?;
            signal_hook::flag::register(
                signal_hook::consts::SIGINT,
                Arc::clone(&self.flag),
            )?;
        }
        Ok(())
    }
    
    fn is_shutdown(&self) -> bool {
        self.flag.load(Ordering::SeqCst)
    }
    
    fn clone_flag(&self) -> Arc<AtomicBool> {
        Arc::clone(&self.flag)
    }
}
```

#### 4.10.1 Command Injection Prevention (SEC-P0-001)

**Threat**: App argument passed to subprocess could enable shell injection.

**Validation**:
```rust
fn validate_app_target(app: &str) -> Result<AppTarget, ServeError> {
    // Only allow: module.path:object or module.path:factory()
    let re = Regex::new(r"^[a-zA-Z_][a-zA-Z0-9_.]*:[a-zA-Z_][a-zA-Z0-9_]*(\(\))?$")?;
    
    if !re.is_match(app) {
        return Err(ServeError::InvalidAppFormat { app: app.to_string() });
    }
    
    // Reject shell metacharacters
    let forbidden = ['|', '&', ';', '$', '`', '\\', '"', '\'', '<', '>', '\n'];
    if app.chars().any(|c| forbidden.contains(&c)) {
        return Err(ServeError::ShellMetacharacters { app: app.to_string() });
    }
    
    Ok(AppTarget::parse(app)?)
}
```

#### 4.10.2 Path Traversal Protection (SEC-P0-002)

**Threat**: Auto-discovery could scan files outside project directory.

**Validation**:
```rust
fn validate_scan_path(path: &Path, project_dir: &Path) -> Result<PathBuf, ServeError> {
    let canonical = path.canonicalize()?;
    let project = project_dir.canonicalize()?;
    
    // Must be within project directory
    if !canonical.starts_with(&project) {
        return Err(ServeError::PathTraversal { path: path.to_path_buf() });

    Ok(canonical)
}
```

#### 4.10.3 Safe PID File Creation (SEC-P0-003)

**Threat**: TOCTOU race condition could overwrite arbitrary files via symlink.

**Solution**: Use `O_EXCL` flag:
```rust
fn write_pid_file_safe(path: &Path, pid: u32) -> Result<(), ServeError> {
    use std::os::unix::fs::OpenOptionsExt;
    
    let file = std::fs::OpenOptions::new()
        .write(true)
        .create_new(true)  // O_EXCL: fail if exists
        .mode(0o644)
        .open(path)?;
    
    use std::io::Write;
    writeln!(&file, "{}", pid)?;
    Ok(())
}
```

#### 5.2.1 Detection Flow

#### 5.2.2 Python AST Detection Script

```python
# python/detect_app.py (called by Rust)
import ast
import sys
from pathlib import Path

def detect_app(file_path: str) -> str | None:
    """Detect ASGI/WSGI app in Python file."""
    with open(file_path) as f:
        tree = ast.parse(f.read())
    
    for node in ast.walk(tree):
        if isinstance(node, ast.Assign):
            for target in node.targets:
                if isinstance(target, ast.Name) and target.id in ('app', 'application'):
                    if isinstance(node.value, ast.Call):
                        func = node.value.func
                        if isinstance(func, ast.Name) and func.id in ('FastAPI', 'Flask', 'Starlette'):
                            module = Path(file_path).stem
                            return f"{module}:{target.id}"
    return None

def find_factory_functions(tree: ast.Module) -> list[str]:
    """Find functions that return ASGI/WSGI apps (PY-P0-002)."""
    factories = []
    factory_names = ('create_app', 'make_app', 'get_app', 'application', 'get_application')
    app_constructors = ('FastAPI', 'Flask', 'Starlette', 'get_wsgi_application')
    
    for node in ast.walk(tree):
        if isinstance(node, ast.FunctionDef) and node.name in factory_names:
            for child in ast.walk(node):
                if isinstance(child, ast.Return) and isinstance(child.value, ast.Call):
                    func = child.value.func
                    if isinstance(func, ast.Name) and func.id in app_constructors:
                        factories.append(f"{node.name}()")
                        break
    return factories

def detect_all(file_path: str) -> dict:
    """Detect both direct apps and factory functions."""
    with open(file_path) as f:
        tree = ast.parse(f.read())
    
    result = {
        "app": detect_app(file_path),
        "factories": find_factory_functions(tree)
    }
    return result

if __name__ == "__main__":
    result = detect_app(sys.argv[1])
    if result:
        print(result)
        sys.exit(0)
    sys.exit(1)
```

### 5.3 Instant Restart (File Watching)

#### 5.3.0 Fresh Process Guarantee (PY-P0-004)

> [!IMPORTANT]
> Each restart creates a fresh Python interpreter with clean state.

**Guarantees**:
- Fresh `sys.modules` (no stale imports)
- Clean global state
- No shared memory with previous process
- `if __name__ == "__main__"` blocks do not execute (correct behavior)

This is inherent to the subprocess model and avoids the pitfalls of in-memory hot module replacement.

#### 5.3.1 Watcher State Machine

```rust
use notify::{Watcher, RecursiveMode, watcher};
use std::sync::mpsc::channel;
use std::time::{Duration, Instant};

enum WatcherState {
    Idle,
    Restarting { since: Instant },
    Debouncing { last_event: Instant },
}

const DEBOUNCE_MS: u64 = 300;
const RESTART_COOLDOWN_MS: u64 = 500;

fn watch_loop(project_dir: &Path, reload_delay: Duration) {
    let (tx, rx) = channel();
    let mut watcher = notify::recommended_watcher(tx)?;
    
    let mut state = WatcherState::Idle;
    
    loop {
        match rx.recv_timeout(Duration::from_millis(100)) {
            Ok(event) => {
                if should_ignore(&event) { continue; }
                
                match state {
                    WatcherState::Idle => {
                        state = WatcherState::Debouncing { 
                            last_event: Instant::now() 
                        };
                    }
                    WatcherState::Debouncing { .. } => {
                        state = WatcherState::Debouncing { 
                            last_event: Instant::now() 
                        };
                    }
                    WatcherState::Restarting { .. } => {
                        // Ignore events during restart
                    }
                }
            }
            Err(RecvTimeoutError::Timeout) => {
                // Check if debounce period elapsed
                if let WatcherState::Debouncing { last_event } = state {
                    if last_event.elapsed() > reload_delay {
                        state = WatcherState::Restarting { since: Instant::now() };
                        do_restart();
                        state = WatcherState::Idle;
                    }
                }
            }
        }
    }
}

fn should_ignore(event: &Event) -> bool {
    // Only watch files in dependency graph (Velo advantage)
    // Ignore: __pycache__, .git, node_modules, .venv
    let path = &event.paths[0];
    if path.extension() != Some("py") { return true; }
    if path.to_string_lossy().contains("__pycache__") { return true; }
    if path.to_string_lossy().contains(".git") { return true; }
    false
}
```

#### 5.3.2 Smart Filtering (Velo Advantage)

If Static Import Graph is available:
- Only watch files that are in the dependency graph
- Ignore unrelated Python files

fn should_watch(path: &Path, graph: &Option<ImportGraph>) -> bool {
    if let Some(graph) = graph {

}
