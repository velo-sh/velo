## 1. Executive Summary

### 1.1 Background

Phase 1 (Tachyon Launcher) is complete, implementing `uv.lock`-based environment fingerprinting and `sys.path` caching. However, benchmarks reveal:

| Project | CPython | Velo (cached) | Result |
|---------|---------|---------------|--------|
| FastAPI | 527ms | 558ms | ❌ 6% slower |
| Django | 415ms | 412ms | ✅ 1% faster |
| DataScience | 184ms | 202ms | ❌ 10% slower |

**Problem Analysis**: Current path caching only saves ~10-20ms, but subprocess overhead negates the gains.

### 1.2 Phase 1.5 Goals

Before advancing to Zygote (Phase 3), we need to solidify infrastructure:

1. **Enhanced Environment Detection** — Prevent ABI mismatch crashes
2. **Startup Diagnostics** — Help users identify performance bottlenecks
3. **Environment Integrity Checking** — Detect environment pollution
4. **Prepare for Zygote** — Collect necessary metadata

### 2.1 Cache Structure Upgrade

#### 2.1.1 Current Structure

```rust
// src/cache.rs (current)
pub struct EnvCache {
    pub fingerprint: String,      // SHA256 of uv.lock
    pub sys_path: Vec<String>,
    pub python_home: String,

```

#### 2.1.2 Proposed Structure

```rust
// src/cache.rs (proposed)
pub struct EnvCache {
    // === Existing ===
    pub fingerprint: String,
    pub sys_path: Vec<String>,
    pub python_home: String,
    
    // === Phase 1.5: ABI Compatibility ===
    pub python_version: PythonVersion,
    pub abi_tag: String,              // e.g., "cp311"
    pub platform_tag: String,         // e.g., "darwin_arm64"
    
    // === Phase 1.5: Environment Integrity ===
    pub packages_hash: String,        // SHA256 of sorted `pip freeze`
    pub critical_env_vars: Vec<EnvVar>,
    
    // === Phase 1.5: Metadata ===
    pub created_at: u64,              // Unix timestamp
    pub velo_version: String,         // Cache format version
}

#[derive(Archive, Deserialize, Serialize)]
pub struct PythonVersion {
    pub major: u8,
    pub minor: u8,
    pub patch: u8,
}

#[derive(Archive, Deserialize, Serialize)]
pub struct EnvVar {
    pub name: String,
    pub value: String,
}
```

#### 2.1.3 Cache Version Compatibility

```rust
const CACHE_VERSION: u32 = 2;  // Bump from 1 to 2 for Phase 1.5

impl EnvCache {
    pub fn is_compatible(&self) -> bool {
        // Old caches without version field are incompatible
        self.cache_version == CACHE_VERSION
    }
}
```

> [!IMPORTANT]
> Upgrading the cache structure will invalidate old caches. Auto-rebuild on first run is required.

### 2.2 Python ABI Detection

#### 2.2.1 Detection Commands

```bash
# Get Python version
python -c "import sys; print(f'{sys.version_info.major}.{sys.version_info.minor}.{sys.version_info.micro}')"
# Output: 3.11.5

# Get ABI tag (for C-Extension compatibility)
python -c "import sysconfig; print(sysconfig.get_config_var('SOABI'))"
# Output: cpython-311-darwin

# Get platform tag
python -c "import sysconfig; print(sysconfig.get_platform().replace('-', '_').replace('.', '_'))"
# Output: macosx_14_0_arm64
```

#### 2.2.2 Rust Implementation

```rust
// src/python_info.rs (new file)

use std::process::Command;
use anyhow::Result;

pub struct PythonInfo {
    pub version: PythonVersion,
    pub abi_tag: String,
    pub platform_tag: String,
}

impl PythonInfo {
    pub fn detect(python_path: &Path) -> Result<Self> {
        let script = r#"
import sys, sysconfig
v = sys.version_info
print(f"{v.major}.{v.minor}.{v.micro}")
print(sysconfig.get_config_var('SOABI') or 'unknown')
print(sysconfig.get_platform().replace('-', '_').replace('.', '_'))
"#;
        
        let output = Command::new(python_path)
            .args(["-c", script])
            .output()?;
        
        // Parse output...
    }
    
    pub fn is_abi_compatible(&self, cached: &PythonInfo) -> bool {
        // ABI tag must match exactly for C-Extension compatibility
        self.abi_tag == cached.abi_tag
    }
}
```

### 2.3 Startup Diagnostics (`velo run --profile`)

#### 2.3.1 Feature Description

Provides detailed startup time breakdown to help users identify slow startup root causes.

#### 2.3.2 Implementation Strategy

**Option A: sitecustomize.py Injection (Recommended)**

```python
# sitecustomize.py temporarily injected into PYTHONPATH by Velo
import sys
import time

_velo_import_times = {}
_velo_original_import = __builtins__.__import__

def _velo_timed_import(name, *args, **kwargs):
    start = time.perf_counter()
    result = _velo_original_import(name, *args, **kwargs)
    elapsed = (time.perf_counter() - start) * 1000
    if elapsed > 1.0:  # Only track imports > 1ms
        _velo_import_times[name] = elapsed
    return result

__builtins__.__import__ = _velo_timed_import

import atexit
@atexit.register
def _velo_report():
    import json
    with open('/tmp/velo_profile.json', 'w') as f:
        json.dump(_velo_import_times, f)
```

**Option B: -X importtime (Python 3.7+)**

```bash
python -X importtime script.py 2>&1 | velo-parse-importtime
```

> [!TIP]
> Option A provides finer-grained control but requires maintaining Python code.
> Option B is simpler but output format depends on Python version.

### 2.5 Environment Integrity Checking

#### 2.5.1 Packages Hash

```rust
impl EnvCache {
    pub fn compute_packages_hash(python: &Path) -> Result<String> {
        // Run: pip freeze | sort | sha256sum
        let output = Command::new(python)
            .args(["-m", "pip", "freeze", "--local"])
            .output()?;
        
        let mut packages: Vec<&str> = output.stdout
            .lines()
            .collect();
        packages.sort();
        
        Ok(sha256(&packages.join("\n")))
    }
}
```

#### 2.5.2 Environment Drift Detection

```
⚠️  Environment Drift Detected
    
    Packages changed since last run:
    ├─ + requests-oauthlib==1.3.1  (added)

    └─ - deprecated-lib==0.1.0    (removed)
```

## 7. Risks & Mitigations

| Risk | Probability | Impact | Mitigation |
|------|------------|--------|------------|
| Cache version upgrade breaks existing users | High | Low | Auto-rebuild on version mismatch |
| `--profile` overhead affects benchmark accuracy | Medium | Medium | Profile overhead itself, subtract from totals |
| Different Python builds have inconsistent SOABI | Low | Medium | Graceful fallback if SOABI unavailable |
